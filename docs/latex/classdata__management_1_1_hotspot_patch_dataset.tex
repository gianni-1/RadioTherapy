\doxysubsection{Detailed Description}
\begin{DoxyVerb}Dataset, das aus jedem Input/Target-Cube Hotspot-Patches extrahiert und als einzelne Trainingssamples zurückgibt.
Nutzt extract_hotspot_patches(volume, ...), um Patch-Startpositionen zu bestimmen.
Jeder __getitem__ gibt einen Patch (Input, Target, Energy) zurück.
\end{DoxyVerb}
