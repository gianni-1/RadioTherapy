\doxysubsection{Detailed Description}
\begin{DoxyVerb}Dataset that loads input/output .npy cubes and parses the energy level from the folder name.
Expects directory structure:
  root_dir/
    <section>/         # e.g. "training"
      <energy_folder>/ # e.g. "11_5"
        inputcube/     # contains input .npy files
        outputcube/    # contains target .npy files
\end{DoxyVerb}
